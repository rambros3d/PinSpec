# Spec Delta

## REMOVED Requirements

### Requirement: Canvas toggle produces visible placement feedback

**Reason**: The floating canvas toggle is removed; rings now follow enabled bubbles.

**Migration**: Use the bubble-driven visibility rule in `placement-controls-relocation`.

### Requirement: Canvas toggle activates the Placement panel

**Reason**: There is no canvas toggle to activate the panel.

**Migration**: Open the Placement tab from the existing drawer or dock tab strip.
